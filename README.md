Adventure Game: Robot Repair — навчальний проєкт, геймдизайн, РФКІТ 2026/27

## Щоденник розробника

### 22.09.2026 — Юніт 1: персонаж і рух

**Що зроблено:**
- Налаштовано 2D-сцену `MainScene` та додано спрайт персонажа Рубі.
- Створено `Tilemap` та палітру `RubyPalette`, усунуто щілини між блоками шляхом зміни PPU на 64.
- Реалізовано рух персонажа через новий `Input System` та скрипт `MyPlayerController`.

**Що не вийшло або забрало найбільше часу:**
- Налаштування `Input Action Composite` для клавіш керування та збереження палітри в потрібну папку проекту.

**Що зрозумів про Update і Time.deltaTime:**
- `Update` викликається кожен кадр, а `Time.deltaTime` дозволяє прив'язати швидкість руху до реального часу (секунд), а не до частоти кадрів комп'ютера.

**Що робитиму далі:**
- Переходитиму до Юніта 2 (додавання колізій, фізики `Rigidbody2D` та перешкод).



### 28.10.2026 — Юніт 2: оточення і фізика
**Що зроблено:** Налаштовано Y-сортування для персонажа та декорацій, реалізовано фізичний рух персонажа через FixedUpdate та MovePosition, додано колайдери для ящика та Tilemap з водою (з Composite Collider 2D).
**Що не вийшло або забрало найбільше часу:** Виправлення колайдерів на тайлах підлоги та налаштування Rule Tile, щоб прибрати «невидимі стіни».
**Що зрозумів про FixedUpdate і колайдери:** Update підходить для зчитування вводу, але фізику потрібно обраховувати у FixedUpdate через MovePosition, щоб уникнути тремтіння при зіткненнях. Collider Type = None на тайлах підлоги потрібен, щоб Tilemap Collider 2D не створював колайдери під ногами персонажа.
**Що в рівні вийшло не так, як у фізичному паспорті, і чому:** Деякі декорації розміщено інакше для зручності обходу та тестування колізій.
**Що робитиму далі:** Переходитиму до Юніту 3 — створення систем здоров'я, тригерів та зон шкоди.
